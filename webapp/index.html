Azure OpenAI Realtime Demo

音声デモを選択し、Function URL を確認して管理者から共有された Function キーを入力してください。一時トークンはブラウザーから Azure Function に直接 POST して取得します。

既定の Function URL は各ページで /api/demo-config から取得します。設定がない場合や静的ホストでは手動入力してください。別の Function URL にも変更できます。

WebRTC は Function キーのみを使用します。WebSocket は同じホストの /realtime-relay 認証専用に、別の Demo キーも使用します。Demo キーは Function に送信しません。

ブラウザーは client_secrets が発行する短期トークンを使用します。Entra 認証はバックエンドのみです。キーは URL やブラウザーのストレージに保存しません。
