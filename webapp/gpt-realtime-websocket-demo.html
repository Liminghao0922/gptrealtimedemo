Azure OpenAI リアルタイム WebSocket デモ

指定した Azure Function から直接一時トークンを取得し、同じホストの /realtime-relay 経由で Realtime WebSocket に接続します。

ブラウザーは client_secrets が発行する短期トークンを使用します。Entra 認証はバックエンドのみです。

接続・音声設定（変更後は再接続）

既定の Function URL を読み込み中です。取得できない場合は手動入力してください。

既定の URL は /api/demo-config から取得します。URL を変更すると入力済みの Function キーは消去されます。 Demo キーはリレーにのみ送信し、Function キーはリレーや Azure OpenAI に送信しません。

入力文字起こしは音声対話と並行する別処理です。AI の発話字幕とは異なり、AI の応答後に到着することもあります。 同じ発話で「無効 / Whisper / GPT / デプロイ名」を比較し、失敗イベントも確認してください。自動フォールバックは行いません。
